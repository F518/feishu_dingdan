# 飞书配置清单

## 自建应用

- 创建企业自建应用。
- 开启机器人能力。
- 将应用可见范围设置为试点员工和财务管理员。
- 将机器人加入试点报销群。
- 配置事件订阅方式：
  - 低代码/集成平台能直接接事件时，优先接入平台触发器。
  - 如果需要长连接或回调，由平台内置连接器承接，不部署到员工电脑。

## 事件订阅

必须订阅：

- `im.message.receive_v1`

建议后续订阅：

- 消息撤回事件，用于标记员工撤回资料。
- 审批实例状态变更事件，用于回写审批结果。

## 权限范围

按最小权限申请。初版通常需要：

- 机器人接收和回复消息。
- 读取消息内容。
- 下载消息中的图片或文件资源。
- 发送卡片或文本确认消息。
- 访问审批应用。
- 创建原生审批实例。
- 上传审批附件。
- 读取用户 open_id/user_id 映射所需通讯录信息。
- 访问多维表格记录。

## 审批模板信息

从现有报销审批模板确认：

- `approval_code`
- 每个表单控件 ID
- 附件控件类型是 `image` 还是 `attachment`
- 是否需要发起人自选审批人
- 是否需要发起人选择部门
- 是否允许应用以员工为发起人创建审批实例

## 多维表格

按 `config/bitable-schema.json` 建表。建议表名：

- `报销机器人台账`
- `字段映射`
- `错误日志`

权限建议：

- 员工不直接编辑台账。
- 财务可查看和补录。
- 应用机器人可读写。
- 管理员可维护字段映射。

## 上线顺序

1. 单群试点。
2. 只识别和写台账，不提交审批。
3. 开启确认卡片。
4. 开启确认后提交审批。
5. 扩大到更多部门。
