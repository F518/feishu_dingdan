# 验收测试计划

## 测试前准备

- 已配置试点群。
- 已创建多维表格台账。
- 已填写审批字段映射。
- 已准备测试发票和行程单。
- 已确认测试员工可以发起目标报销审批。

## 用例

| 编号 | 场景 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| T01 | 单张发票和行程单 | 员工发送 1 张发票和 1 份行程单 | 台账新增记录，状态进入 `pending_confirm` |
| T02 | 确认提交 | 员工点击确认卡片 | 创建审批实例，状态进入 `submitted` |
| T03 | 多张发票 | 员工发送多张发票和 1 份行程单 | 合计金额正确，生成单个确认卡片 |
| T04 | 缺行程单 | 员工只发送发票 | 状态进入 `need_more_info`，机器人提示补充 |
| T05 | 重复资料 | 重复发送同一发票 | 状态进入 `duplicate`，不重复提交审批 |
| T06 | AI 识别失败 | 上传模糊图片 | 状态进入 `need_more_info` 或 `failed`，不提交审批 |
| T07 | 非发送人确认 | 群内其他人点击确认 | 拒绝提交，提示只能由发送人确认 |
| T08 | 审批权限不足 | 临时移除审批权限后提交 | 台账记录错误，通知管理员 |
| T09 | 附件过大 | 上传超过限制的附件 | 标记失败并提示重新上传 |
| T10 | 审批模板停用 | 使用停用模板提交 | 标记失败，错误信息包含审批模板不可用 |

## 通过标准

- 所有成功路径必须产生可追踪的审批实例 ID。
- 所有失败路径必须写入错误类型和错误信息。
- 任何异常都不能静默提交审批。
- 重复资料不能创建重复审批。
- 员工金额和票据信息不在群内公开展示。

## 最小本地检查

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\validate-config.ps1
```

该检查只验证配置文件可解析，不代表飞书线上流程已通过。
